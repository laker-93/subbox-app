Getting started · Windows · Rekordbox

Put your Rekordbox playlists on Sub-box

Install the Sub-box app, sign in, and upload your Rekordbox playlists with their tracks, cue points and folders. Setting up takes about ten minutes; the upload depends on how much music you send.

You’ll need
  • Your Sub-box username and password. Sub-box is in private beta: no account yet? Click Request an invite on the app’s start screen.
  • Your Rekordbox library on this Windows PC, with the music files where Rekordbox expects them.
Part 1 of 3

Install Sub-box

  1. Download Sub-box. This one file works on every Windows PC.

    Download for Windows

    If your browser says the file isn’t commonly downloaded, choose Keep. In Edge, that’s the … menu, then Keep, Show more, Keep anyway.

  2. Run it. Open the file you downloaded. Windows shows a blue box, Windows protected your PC. Click More info, then Run anyway.

    Why? Sub-box isn’t signed with a Microsoft certificate yet, so Windows asks you to confirm you trust it. You only see this when installing.

  3. Finish installing. Keep the default choices and click through to Finish. Sub-box opens, and there’s a shortcut on your desktop.

Sub-box checks for new versions when it starts.

Part 2 of 3

Sign in

  1. Click Login

  2. Enter your username and password and click Login. Leave Remember me ticked so you stay signed in.

Part 3 of 3

Upload your Rekordbox playlists

  1. Export your collection from Rekordbox. In Rekordbox, choose File›Export Collection in xml format and save the file in your Documents folder.

    Sub-box finds each track where Rekordbox says it is, so don’t move or rename music files before you upload.

  2. Pick the file in Sub-box. Click Sync at the top right 1, choose Rekordbox 2, then click Select XML File 3 and pick the file you just saved.

  3. Click Upload. Every playlist is ticked. Untick any you don’t want to send. Leave Import metadata only unticked.

  4. Wait for Upload Complete. Keep Sub-box open while it works. A big library can take a while.

  5. Find your playlists. Click Library at the top right. Your playlists are in the sidebar, in the same folders as in Rekordbox, with their cue points.

If something goes wrong

Common problems

It says “Storage Limit Reached”

The playlists you ticked add up to more than the space on your account. Nothing was uploaded. Go back, untick some playlists and try again.

Some tracks “could not be read from this computer”

Those files were moved or deleted after Rekordbox last saw them. Everything else uploaded normally. In Rekordbox, find the missing files (they show a warning icon), then export the collection again. Then put the fixed tracks in a new playlist and upload just that one.

The upload failed

Click Copy details on the error screen and paste it to us on Discord. Your library isn’t changed by a failed upload, so it’s safe to click Retry.

I want to add more music later

Do the upload part again and tick only the new playlists. Tracks you add to Rekordbox later need a new upload to appear in Sub-box.
