Part 1 of 3

Install Sub-box

  1. Download Sub-box. This one file works on every Windows PC.

    Download for Windows

    If your browser says the file isn’t commonly downloaded, choose Keep. In Edge, that’s the … menu, then Keep, Show more, Keep anyway.

  2. Run it. Open the file you downloaded. Windows shows a blue box, Windows protected your PC. Click More info, then Run anyway.

    Why? Sub-box isn’t signed with a Microsoft certificate yet, so Windows asks you to confirm you trust it. You only see this when installing.

  3. Finish installing. Keep the default choices and click through to Finish. Sub-box opens, and there’s a shortcut on your desktop.

Sub-box checks for new versions when it starts.

Part 2 of 3

Sign in

  1. Click Login

  2. Enter your username and password and click Login. Leave Remember me ticked so you stay signed in.

Part 3 of 3

Upload a folder of music

  1. Choose a folder of music. Click Sync at the top right 1, choose Watch 2, then click Select Directory 3 and pick a folder with some of your tracks in it. Folders inside it are included.

    Start small. A folder with a few favourite tracks is enough to try Sub-box. You can point it at a bigger folder later.

  2. Click Start Watching. Sub-box starts uploading every track in the folder.

    Your files stay where they are. Sub-box doesn’t move, rename or convert them. It does add a small ID tag to each file it uploads, so it can recognise that track later.

  3. Wait for Watching for new files… While it works it shows Uploading 3/8 and the file it’s on. Keep Sub-box open until it finishes.

  4. Find your tracks. Click Library at the top right, then Tracks in the sidebar. Sub-box sorts each upload into your library, so the last tracks can take a minute or two to appear.

  5. Add more any time. While Sub-box is open, anything new you save into that folder is uploaded automatically, and it carries on watching the next time you open the app. Click Stop Watching to turn it off.

If something goes wrong

Common problems

Some files “could not be read and were not uploaded”

Sub-box couldn’t open those files to tag them, usually because they are damaged or still being copied. Everything else uploads normally. Sub-box tries them again on every pass, so a file that finishes copying is picked up by itself.

Nothing uploads

Sub-box uploads MP3, FLAC, WAV, AAC, M4A, OGG, Opus and WMA files. It skips folders whose name starts with a dot. Check the folder you chose has music of those kinds in it, then click Stop Watching and Start Watching again.

It says “Error uploading”

Take a screenshot and send it to us on Discord. Nothing in your folder is changed by a failed upload, and Sub-box tries again on its next pass.

When you’re ready

Bring in your playlists and cue points

A folder brings in tracks. If you use Rekordbox or Serato, upload your library from there too and Sub-box adds your playlists, folders, cue points and beatgrids.
